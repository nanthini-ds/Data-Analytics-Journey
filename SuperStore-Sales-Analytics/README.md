
# SuperStore Sales Analytics Project

## Project Overview
This project analyzes SuperStore sales data using Python and Power BI.

The project focuses on:
- Sales Analysis
- Profit Analysis
- Category Performance
- Regional Performance
- Customer Segments
- Sales Trends
- Discount vs Profit Analysis

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI

## Key Insights
- Office Supplies generated highest sales.
- Technology category achieved highest profit.
- Sales increased steadily from 2011 to 2014.
- High discounts negatively affected profit.
- Central region recorded highest sales.
